## How this portfolio is organized

Each folder represents one dataset — either an open/public dataset, or anonymized data 
derived from real client work. Inside each:
- `data/raw` — source description (raw file not committed for privacy)
- `data/processed` — cleaned dataset used across all analyses
- `01-data-cleaning` — cleaning and preparation notebook
- `02-...`, `03-...` — one analysis per business question, built on the cleaned dataset
